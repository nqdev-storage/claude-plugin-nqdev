# CLAUDE.md Templates

These are production-ready templates included in nqdev-init-agents v1.4.0.

## Available Templates

### 1. SOURCE_CODE.md (105 lines)
Code organization, naming conventions, and style guidelines.

**Includes**:
- Directory structure recommendations
- Naming conventions (variables, functions, classes)
- Code style and formatting
- Import/export patterns
- Comment guidelines

### 2. API_ENDPOINTS.md (240 lines)
API design, versioning, error handling, and best practices.

**Includes**:
- REST/GraphQL design principles
- Versioning strategies
- Authentication patterns
- Error response formats
- Rate limiting guidelines
- Documentation standards

### 3. COMPONENTS.md (215 lines)
UI component patterns, structure, and state management.

**Includes**:
- Component organization
- Prop definitions
- State management patterns
- Testing strategies
- Accessibility requirements
- Documentation templates

### 4. TESTING.md (290 lines)
Testing standards for unit, integration, and E2E tests.

**Includes**:
- Unit testing guidelines
- Integration test patterns
- E2E test strategies
- Mocking and stubbing
- Coverage targets
- Test organization

### 5. DATABASE.md (350 lines)
Database migrations, query patterns, indexing, and performance.

**Includes**:
- Migration strategies
- Query optimization
- Indexing guidelines
- Connection pooling
- Backup procedures
- Performance monitoring

### 6. DOCUMENTATION.md (330 lines)
Writing style, code examples, and API documentation.

**Includes**:
- Writing style guide
- Code example formatting
- README structure
- API documentation format
- Changelog standards
- Comment style guide

## Total

**1,530 lines** of production-ready guidance across all templates.

These templates are automatically included in generated CLAUDE.md files.

To customize, edit the generated CLAUDE.md file directly.
